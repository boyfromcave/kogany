`koganyd` v1.8.0-ycash.beta1: Kogany, the Ycash node on Zakura, with the vault network upgrade and
the Ycash Yellowback (YED) rule module.

**Pre-release.** kogany is not a qualified Ycash node line yet (kogany plan K-19). Run it on the
Ycash testnets only; expect resyncs and breaking changes between pre-releases.

**What works**

- Following Ycash mainnet and the re-forked Ycash testnet (`fast` profile), and regtest.
- The vault primitive and the Yellowback module, as ycash6 enforces them.
- The stock Ycash RPCs, the vault `set_*` / `vault_*` RPCs and the `yed_*` RPCs, `rpcversion` 8.

**What does not yet**

- The `slow` testnet profile (P2P 18933, RPC 18932) has no config selector.
- No wallet in the node; no Windows or Intel macOS build.
- The binaries link the system RocksDB: `sudo apt install librocksdb8.9` on Ubuntu 24.04,
  `brew install rocksdb` on macOS.

**Getting started**

```sh
sha256sum -c SHA256SUMS --ignore-missing
cosign verify-blob --bundle SHA256SUMS.cosign.bundle \
  --certificate-identity-regexp '^https://github.com/boyfromcave/kogany/' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS
tar xzf koganyd_v1.8.0-ycash.beta1_linux-x86_64.tar.gz && cd koganyd_v1.8.0-ycash.beta1_linux-x86_64
printf '[network]\nnetwork = "Testnet"\nlisten_addr = "[::]"\n\n[rpc]\nlisten_addr = "127.0.0.1:18832"\n' > testnet.toml
./koganyd -c testnet.toml start
```

Ports: mainnet 8833 / RPC 8832, testnet `fast` 18833 / 18832. Each tarball's `README.txt` has
the details; the [kogany README](https://github.com/boyfromcave/kogany#readme) has the rest.
